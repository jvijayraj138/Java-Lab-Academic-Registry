WEEK 9 - PACKAGES AND INTERFACES

Experiment 1: Creating and Using a User-Defined Package

Aim: To create a user-defined package and access its class from another Java program.

File 1: mypackage/Student.java

package mypackage;

public class Student {
    public String name;
    public int rollNo;

    public Student(String name, int rollNo) {
        this.name = name;
        this.rollNo = rollNo;
    }

    public void display() {
        System.out.println("Student Name: " + name);
        System.out.println("Roll Number: " + rollNo);
    }
}

File 2: Main.java

import mypackage.Student;

public class Main {
    public static void main(String[] args) {
        Student s = new Student("Ravi", 101);
        s.display();
    }
}
Sample Output: 
Student Name: Ravi
Roll Number: 101

Save Student.java inside the mypackage folder. Compile the package class first, then compile and run Main.java from the parent folder.

Experiment 2: Importing Packages

Aim: To demonstrate importing a specific class and using a wildcard package import.

File 1: college/Student.java

package college;

public class Student {
    public void display() {
        System.out.println("This is the Student class.");
    }
}

File 2: college/Faculty.java

package college;

public class Faculty {
    public void display() {
        System.out.println("This is the Faculty class.");
    }
}

File 3: SpecificImport.java

import college.Student;

public class SpecificImport {
    public static void main(String[] args) {
        Student s = new Student();
        s.display();
    }
}

File 4: WildcardImport.java

import college.*;

public class WildcardImport {
    public static void main(String[] args) {
        Student s = new Student();
        Faculty f = new Faculty();

        s.display();
        f.display();
    }
}
Output of SpecificImport: 
This is the Student class.
Output of WildcardImport: 
This is the Student class.
This is the Faculty class.

Experiment 3: Packages and Member Access

Aim: To demonstrate the accessibility of public, private, protected and default members across classes and packages.

File 1: accessdemo/AccessExample.java

package accessdemo;

public class AccessExample {
    public int publicValue = 10;
    private int privateValue = 20;
    protected int protectedValue = 30;
    int defaultValue = 40;

    public void displayInsideClass() {
        System.out.println("Public: " + publicValue);
        System.out.println("Private: " + privateValue);
        System.out.println("Protected: " + protectedValue);
        System.out.println("Default: " + defaultValue);
    }
}

File 2: accessdemo/SamePackage.java

package accessdemo;

public class SamePackage {
    public static void main(String[] args) {
        AccessExample obj = new AccessExample();

        System.out.println("Public: " + obj.publicValue);
        System.out.println("Protected: " + obj.protectedValue);
        System.out.println("Default: " + obj.defaultValue);

        // Private members cannot be accessed directly here.
    }
}

File 3: otherpackage/DifferentPackage.java

package otherpackage;

import accessdemo.AccessExample;

public class DifferentPackage {
    public static void main(String[] args) {
        AccessExample obj = new AccessExample();

        System.out.println("Public: " + obj.publicValue);

        // Private, default and protected members
        // cannot be accessed directly here.
    }
}
Output inside AccessExample: 
Public: 10
Private: 20
Protected: 30
Default: 40
Output of SamePackage: 
Public: 10
Protected: 30
Default: 40
Output of DifferentPackage: 
Public: 10

The examples are separate Java files. A protected member is accessible in a different package through inheritance, subject to Java's access rules.

Experiment 4: Demonstrating CLASSPATH

Aim: To demonstrate how Java locates user-defined packages and classes using CLASSPATH.

File 1: utilities/Calculator.java

package utilities;

public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }
}

File 2: CalculatorMain.java

import utilities.Calculator;

public class CalculatorMain {
    public static void main(String[] args) {
        Calculator c = new Calculator();

        int result = c.add(10, 20);
        System.out.println("Sum = " + result);
    }
}
Output: 
Sum = 30

Compilation and Execution (Windows)

javac -d . utilities/Calculator.java
javac -cp . CalculatorMain.java
java -cp . CalculatorMain

Here, -cp . sets the current directory as the classpath for the command. This demonstrates classpath-based class lookup.

Experiment 5: Package Containing Multiple Classes

Aim: To create a bank package containing Account, Customer and Transaction classes.

File 1: bank/Account.java

package bank;

public class Account {
    public double balance;

    public Account(double balance) {
        this.balance = balance;
    }

    public void displayBalance() {

package bank;

    public String name;

    public Customer(String name) {
        this.name = name;
    }

    public void displayCustomer() {
        System.out.println("Customer: " + name);
    }

File 3: bank/Transaction.java

package bank;

public class Transaction {
    public void deposit(Account account, double amount) {
        account.balance += amount;
        System.out.println("Deposited: " + amount);
    }
}

import bank.Account;
import bank.Customer;

Experiment 6: Defining and Implementing an Interface

Aim: To create a Shape interface and implement it using Circle and Rectangle classes.

interface Shape {
    double area();
}

class Circle implements Shape {
    double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    public double area() {
        return Math.PI * radius * radius;
    }
}

class Rectangle implements Shape {
    double length, breadth;

    Rectangle(double length, double breadth) {
        this.length = length;
        this.breadth = breadth;
    }

    public double area() {
        return length * breadth;
    }
}

public class ShapeDemo {
    public static void main(String[] args) {
        Shape c = new Circle(5);
        Shape r = new Rectangle(4, 6);

        System.out.printf("Circle Area: %.2f%n", c.area());
        System.out.println("Rectangle Area: " + r.area());
    }
}
Output: 
Circle Area: 78.54
Rectangle Area: 24.0

Experiment 8: Interface-Based Polymorphism

Aim: To demonstrate polymorphism using a Vehicle interface reference.

interface Vehicle {
    void start();
}

class Car implements Vehicle {
    public void start() {
        System.out.println("Car starts with a key.");
    }
}

class Bike implements Vehicle {
    public void start() {
        System.out.println("Bike starts with a button.");
    }
}

public class VehicleDemo {
    public static void main(String[] args) {
        Vehicle v;

        v = new Car();
        v.start();

        v = new Bike();
        v.start();
    }
}
Output: 
Car starts with a key.
Bike starts with a button.

Experiment 12: Payment Processing System Using Interfaces

Aim: To develop a payment processing system using an interface and multiple implementations.

import java.util.Scanner;

interface Payment {
    void pay(double amount);
}

class CreditCardPayment implements Payment {
    public void pay(double amount) {
        System.out.println(
            "Paid Rs. " + amount + " using Credit Card."
        );
    }
}

class UPIPayment implements Payment {
    public void pay(double amount) {
        System.out.println(
            "Paid Rs. " + amount + " using UPI."
        );
    }
}

class NetBankingPayment implements Payment {
    public void pay(double amount) {
        System.out.println(
            "Paid Rs. " + amount + " using Net Banking."
        );
    }
}

public class PaymentDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("1. Credit Card");
        System.out.println("2. UPI");
        System.out.println("3. Net Banking");

        System.out.print("Choose payment method: ");
        int choice = sc.nextInt();

        System.out.print("Enter amount: ");
        double amount = sc.nextDouble();

        Payment payment;

        switch (choice) {
            case 1:
                payment = new CreditCardPayment();
                break;
            case 2:
                payment = new UPIPayment();
                break;
            case 3:
                payment = new NetBankingPayment();
                break;
            default:
                System.out.println("Invalid payment method.");
                sc.close();
                return;
        }

        payment.pay(amount);
        sc.close();
    }
}
Sample Output: 
1. Credit Card
2. UPI
3. Net Banking
Choose payment method: 2
Enter amount: 1500
Paid Rs. 1500.0 using UPI.
