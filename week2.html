Week 2: Installation of Java

Aim: To install Java Development Kit (JDK), configure Java on Windows, and execute a simple Java program.

Part A: Installing Oracle JDK

Step 1: Download Java JDK

Open a web browser and visit the official Oracle JDK website. Download the appropriate JDK installer for Windows.

Download Oracle JDK

Step 2: Install JDK

  1. Double-click the downloaded .exe file.
  2. Click Next and follow the installation wizard.
  3. Complete the installation.

Step 3: Verify Java Installation

Open Command Prompt and enter:

java --version

To check the Java compiler, enter:

javac --version

Part B: Configuring Java on Windows

Step 1: Find the JDK Installation Path

Locate the folder where the JDK was installed.

Example: C:\Program Files\Java\jdk-25

Step 2: Set JAVA_HOME

  1. Press Windows + R.
  2. Type sysdm.cpl and press Enter.
  3. Select the Advanced tab.
  4. Click Environment Variables.
  5. Create a system variable named JAVA_HOME.
  6. Set its value to your actual JDK installation folder.

Step 3: Update the PATH Variable

  1. Under System Variables, select Path and click Edit.
  2. Add a new entry: %JAVA_HOME%\bin
  3. Click OK to save the changes.

Step 4: Verify Configuration

Open a new Command Prompt and run:

echo %JAVA_HOME%

java --version

javac --version

Part C: Installing OpenJDK

  1. Open a web browser and visit the OpenJDK website.
  2. Download the Windows x86 64-bit JDK 21.0.11 MSI installer, as specified in the lab material.
  3. Run the installer and complete the installation.
  4. Open Command Prompt and check the Java version.
  5. Update the installation path if required.
  6. Write and run a simple Java program.

OpenJDK Downloads

Part D: Hello World Program

Create a file named HelloWorld.java and enter:

class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Compile the program using:

javac HelloWorld.java

Run the program using:

java HelloWorld

Expected Output

Hello, World!

Note: The exact version number and installation path depend on the JDK version installed on your computer.
