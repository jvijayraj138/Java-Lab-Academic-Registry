Part A: Character Streams

Experiment 1

Read Characters Using Reader and Writer

Aim: To read characters from the keyboard using Reader and display them on the console using Writer.

import java.io.*;

public class ReaderWriterDemo {
    public static void main(String[] args) throws IOException {
        Reader reader = new InputStreamReader(System.in);
        Writer writer = new OutputStreamWriter(System.out);

        System.out.print("Enter text: ");
        int ch;

        while ((ch = reader.read()) != '\n' && ch != -1) {
            writer.write(ch);
        }

        writer.write('\n');
        writer.flush();
    }
}
Sample Output:
Enter text: Hello Java
Hello Java

Type a line and press Enter. On some systems, the input may include a carriage return, which is also treated as a line ending.

Experiment 2

Read a Text File Using FileReader

Aim: To read the contents of a text file using FileReader and display them on the console.

import java.io.*;

public class ReadTextFile {
    public static void main(String[] args) {
        try (FileReader reader = new FileReader("input.txt")) {
            int ch;

            while ((ch = reader.read()) != -1) {
                System.out.print((char) ch);
            }
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
Sample Output:
Hello Java
Welcome to programming.

Create input.txt with the two sample lines in the program's working directory.

Experiment 4

Copy One Text File to Another

Aim: To copy the contents of one text file into another using FileReader and FileWriter.

import java.io.*;

public class CopyTextFile {
    public static void main(String[] args) {
        try (FileReader reader = new FileReader("source.txt");
             FileWriter writer = new FileWriter("destination.txt")) {

            char[] buffer = new char[1024];
            int count;

            while ((count = reader.read(buffer)) != -1) {
                writer.write(buffer, 0, count);
            }

            System.out.println("File copied successfully.");
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
Sample Output:
File copied successfully.

Create source.txt first. Its contents will be copied to destination.txt.

Experiment 5

Count Characters, Words, and Lines

Aim: To count the number of characters, words, and lines in a text file using character streams.

import java.io.*;

public class FileCount {
    public static void main(String[] args) {
        int characters = 0;
        int words = 0;
        int lines = 0;

        try (BufferedReader reader =
                 new BufferedReader(new FileReader("input.txt"))) {
            String line;

            while ((line = reader.readLine()) != null) {
                lines++;
                characters += line.length();

                String trimmed = line.trim();
                if (!trimmed.isEmpty()) {
                    words += trimmed.split("\\s+").length;
                }
            }

            System.out.println("Characters: " + characters);
            System.out.println("Words: " + words);
            System.out.println("Lines: " + lines);
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
Sample Output:
Characters: 26
Words: 5
Lines: 2

For this output, input.txt must contain exactly Hello Java on the first line and Welcome to programming. on the second line. The program counts characters excluding line-ending characters.

Experiment 7

Experiment 9

Concurrent Execution of Multiple Threads

Aim: To create multiple threads and demonstrate their concurrent execution.

class TaskThread extends Thread {
    TaskThread(String name) {
        super(name);
    }

    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(getName() + ": " + i);
        }
    }
}

public class MultipleThreadsDemo {
    public static void main(String[] args) {
        TaskThread t1 = new TaskThread("Thread 1");
        TaskThread t2 = new TaskThread("Thread 2");
        TaskThread t3 = new TaskThread("Thread 3");

        t1.start();
        t2.start();
        t3.start();
    }
}
Possible Output:
Thread 1: 1
Thread 2: 1
Thread 3: 1
Thread 1: 2
Thread 3: 2
Thread 2: 2
Thread 1: 3
Thread 2: 3
Thread 3: 3

The exact order can vary because the scheduler controls thread execution.

Experiment 10

Using the isAlive() Method

Aim: To check whether a thread is running using isAlive().

class AliveThread extends Thread {
    public void run() {
        try {
            Thread.sleep(500);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}

public class IsAliveDemo {
    public static void main(String[] args)
            throws InterruptedException {
        AliveThread t = new AliveThread();

        System.out.println("Before start: " + t.isAlive());

        t.start();
        System.out.println("After start: " + t.isAlive());

        t.join();
        System.out.println("After completion: " + t.isAlive());
    }
}
Sample Output:
Before start: false
After start: true
After completion: false

The middle result is normally true because the thread sleeps for 500 milliseconds, giving the main thread time to check it.

Experiment 11

Using the join() Method

Aim: To make one thread wait for another thread to complete using join().

class WorkerThread extends Thread {
    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println("Worker: " + i);
        }
    }
}

public class JoinDemo {
    public static void main(String[] args)
            throws InterruptedException {
        WorkerThread t = new WorkerThread();
        t.start();

        t.join();

        System.out.println("Worker completed");
        System.out.println("Main thread continues");
    }
}
Sample Output:
Worker: 1
Worker: 2
Worker: 3
Worker completed
Main thread continues
Experiment 12

Using isAlive() and join() Together

Aim: To control thread execution using isAlive() and join().

class MyWorker extends Thread {
    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(getName() + ": " + i);

            try {
                Thread.sleep(200);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return;
            }
        }
    }
}

public class AliveJoinDemo {
    public static void main(String[] args)
            throws InterruptedException {
        MyWorker t1 = new MyWorker();
        MyWorker t2 = new MyWorker();

        t1.setName("Thread 1");
        t2.setName("Thread 2");

        t1.start();
        t2.start();

        System.out.println("Thread 1 alive: " + t1.isAlive());

        t1.join();
        t2.join();

        System.out.println("Thread 1 alive: " + t1.isAlive());
        System.out.println("Thread 2 alive: " + t2.isAlive());
        System.out.println("Both threads completed");
    }
}
Possible Output:
Thread 1: 1
Thread 2: 1
Thread 1 alive: true
Thread 1: 2
Thread 2: 2
Thread 1: 3
Thread 2: 3
Thread 1 alive: false
Thread 2 alive: false
Both threads completed

The order of the first messages can vary. The final three messages appear after both threads finish.
